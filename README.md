# Office Fournitures

Boutique Next.js. Le catalogue vient d'une copie Supabase poussée depuis IGestion. Le site ne se connecte jamais au serveur HFSQL.

En local : `npm run dev` puis [http://127.0.0.1:5173](http://127.0.0.1:5173).

Sans variables Supabase, le site affiche un catalogue d'exemple (réf. 14661).

L'ancienne page vitrine est dans `legacy/vitrine.html`.
